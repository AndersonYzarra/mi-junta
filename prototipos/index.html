Mi Junta

Prototipos de Mi Junta

Prototipos visuales para validar los flujos con stakeholders. No son código de producción. Cada pantalla tiene arriba un selector de estado: Con datos, Vacío, Error y Loading.

Datos de ejemplo

Todas las pantallas usan los mismos datos ficticios.

Lo que se guarda en una pantalla (unirse, editar la junta, fijar el orden, registrar o informar un pago, cerrar sesión) se ve en las demás mientras esta pestaña siga abierta.

Pantallas por flujo

Las pantallas se agregan por lotes. Si un enlace no abre, esa pantalla todavía no está hecha.

Base común

  • assets/estilos.css

    Datos ficticios, textos del catálogo de 03 §2.9, formatos de Perú y validaciones.

    Selector de estado que muestra u oculta los bloques marcados con data-estado.
